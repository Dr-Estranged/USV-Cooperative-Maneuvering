# USV-Cooperative-Maneuvering
Southeast University undergraduate SRTP project. This repo contains MATLAB code reproducing the multi-USV cooperative maneuvering algorithm from the paper: "Noncooperative Game-based Cooperative Maneuvering of Intelligent Surface Vehicles via Accelerated Learning-based Neural Predictors" (IEEE TIV, 2022).
# Code Architecture
All simulation codes in this repository are implemented 100% in MATLAB. In 01_part1-Single-ISV-Modeling-ode45, the fundamental kinematics and kinetics models of a single Intelligent Surface Vehicle (ISV) are established and simulated using the ode45 solver. Building upon this, 02_part2-Nash-Equilibrium-Controller designs a trajectory tracking controller based on a Nash equilibrium seeking strategy to continuously eliminate position and velocity errors. The system is then expanded in 03_part3-Swarm-Cooperative-Maneuvering, which implements a consensus protocol-based action estimator to achieve distributed cooperative maneuvering for the ISV swarm under a constrained communication topology. Finally, 04_part4-Accelerated-Neural-Predictor integrates a physics-informed neural network with an accelerated learning law to efficiently estimate and compensate for unknown nonlinear environmental disturbances.
